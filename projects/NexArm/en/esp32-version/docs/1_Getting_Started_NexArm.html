1. Getting Started ​

1.1 Product Overview ​

NexArm is an open-source six-axis robotic arm designed for embodied intelligence, robotics development, and artificial intelligence applications. Integrating mechanical control, teach programming, leader-follower control, and imitation learning into a single platform, it provides a comprehensive robotics development platform for developers, academic research institutions, and robotics enthusiasts. Compatible with mainstream open-source frameworks such as LeRobot and Hugging Face, it enables quick setup for algorithm validation, data collection, model training, and intelligent control.

NexArm supports fundamental motion control, trajectory teaching, action recording and playback, leader-follower cooperative control, imitation learning data collection, and AI model training and deployment. It can be widely applied in robotics teaching experiments, embodied intelligence research, reinforcement learning and imitation learning development, vision-based grasping, intelligent interaction verification, and personal development projects, helping quickly bridge the gap from robotic arm control to end-to-end AI application deployment.

1.4.2 App Connection ​

NOTE

NexArm is shipped with Bluetooth connection enabled by default. After the robotic arm is powered on, open the app to discover the corresponding Bluetooth device. Pressing KEY2 switches between PS3 controller mode and app control mode.

  • Open the app, tap Robot on the left side, find NexArm in the pop-up options, and tap it to enter the control interface.

  • After entering the control interface, the Mode Selection screen will appear. Tap the Bluetooth icon in the upper-right corner to connect Bluetooth first.

  • Connect NexArm to the original power adapter, turn on the power switch, and wait a few seconds. Tap the Bluetooth connection icon in the app. When the Bluetooth list appears, find Nex_Arm and tap it to connect.

  • After a successful connection, the Bluetooth list window closes automatically, and the notification Bluetooth is connected is displayed.

1.4.4 Calling Action Groups ​

  1. In either control mode, tap the action group button.

  1. After tapping the button, the Action Group screen appears. Tap Add to add an action group.

NOTE

The action group calling function requires the action group ID to be confirmed in the host software in advance, and the action group with the corresponding ID must be downloaded to NexArm. Otherwise, this function cannot be used. For the action group download procedure, refer to 1.6 Action Group Editing and Execution in this document.

  1. Action group 0 is downloaded to NexArm from the host software in advance. In this example, the action group is named 111, and the action group ID is set to 0. After the settings are complete, tap OK.

  2. After entering the information, tap OK. The Action Group window closes, and the pop-up appears. Tap the action group button again. The action group named 111 is now shown in the list. Tap it to run the action group with the corresponding ID.

  3. Press and hold the 111 item in the list. The delete and edit options for the action group will appear.

1.5.2.6 Teach Edit ​

  • Function Entry

    Click Teach Edit in the left-side menu to enter the corresponding interface.

  • Local Teach Edit Steps

    1. Click Enter Edit. All NexArm servos power off, allowing any servo to be manually moved by hand.
    2. Click Start Record, then move any servo by hand. The system automatically records the motion.
    3. Click Stop Record. The system stops recording the current motion automatically and saves the recorded action.
    4. Click Play. NexArm automatically executes the action recorded in step 2 and stops automatically after playback completes.
    5. Click Stop Play to interrupt an action currently playing.
    6. Click Clear Data to clear recorded actions.
    7. Click Query Status to print information such as current playback frame count in the system log.
    8. Click Exit Edit. All NexArm servos power on, and Local Teach Edit mode exits.

  • Synchronizer Teach Steps

NOTE

This section applies only to the NexArm Ultimate Kit equipped with a leader arm.

  1. Power on the leader arm.
  2. Click Enter Sync Teach. NexArm automatically connects to the leader arm and synchronizes motion.
  3. Click Start Record, then operate the leader arm. NexArm automatically performs the same motion, recording and saving the current action.
  4. Click Stop Record. The system stops recording the current motion automatically and saves the recorded action.
  5. Click Play. NexArm automatically executes the action recorded in step 2 and stops automatically after playback completes.
  6. Click Stop Play to interrupt an action currently playing.
  7. Click Clear Data to clear recorded actions.
  8. Click Query Status to print information such as current playback frame count in the system log.
  9. Click Exit Edit. All NexArm servos power on, and Sync Teach Edit mode exits.

1.6 Action Group Editing and Execution ​

1.6.1 Editing Action Groups ​

  1. After connecting the robotic arm to the host software, switch to the Servo and Action Group interface and click Read Pos.
  1. After reading positions, the real-time position of each ID is displayed on the right.
  1. Click Add in the Action Group Editor section to add current angles of all servos as one action frame. Click an action group number to run that frame. After selecting a number, modify Frame Time (ms) and click Update to set the time required for running this frame.
  1. After clicking an action frame, adjust the individual servo Acc value, from 0 to 255, and click Update to adjust servo acceleration for that frame.
  1. When editing a multi-frame action group, select an action group number and click Delete to delete that frame. Click Clear to clear all actions. After selecting an action number, click Move Up or Move Down to adjust its position. Click Save (.d6a) to save the current action group as a .d6a file. Click Load to parse a .d6a file into an action group and import it into NexArm.
  1. Factory preset action groups are provided under 1. Tutorials\1. Getting Started\04 Appendix\04 Factory Action Groups. Flashing to NexArm can be performed using the method above.

1.6.2 Running and Downloading Action Groups ​

After action group editing is complete, click Run Online (PC) in the Run_Download section to run all edited action groups. Modify Group ID, the action group number, and click Download to download the current action group to the robotic arm controller. Click Run (Board) to run the action group downloaded to the controller. Click Erase to delete all action groups downloaded to the controller. Click Stop to stop the currently running action group.

1.7.1 PS3 Controller Overview ​

NexArm is equipped with a PS3 protocol-compatible wireless controller held with both hands, with a D-pad on the left, four face buttons △, ○, ×, □ on the right, Select and Start in the center, and a PS button on the front. Two sets of shoulder buttons L1/L2 and R1/R2 on top, along with two pressable analog sticks (L3/R3). Communication is handled via Bluetooth connected to the controller, with a built-in battery, USB charging, and player indicators. It is used to adjust arm posture and servos in coordinate/servo control modes, as well as chassis forward movement, strafing, and turning.

1.7.3 Wireless Controller Connection ​

  1. Look into the Bluetooth pairing code on the back of the controller.
  1. Connect NexArm to the PC software, then change the NexArm Bluetooth pairing code to match the controller Bluetooth pairing code. For detailed host software connection and usage, refer to 1.5 PC Software Control.
  1. Power on NexArm again. The display will show NexArm posture information.
  1. Press KEY2. The display shows the prompt Switch to BLE Press again to confirm switch.
  1. Press KEY2 again to start switching. After the switch is successful, the screen restarts. The active mode is app Bluetooth control, and the robotic arm can be controlled from the app.
  1. Press KEY2 again. The display shows the prompt Switch to PS3 Press again to confirm switch.
  1. Press KEY2 again to start switching. After the switch is successful, the screen restarts. Keep NexArm in this state.
  1. Press and hold the controller P3 button. The four indicator lights begin flashing.
  1. After flashing for 2 to 4 seconds, indicators 2, 3, and 4 stop flashing, and indicator 1 stays on. This indicates that the controller has connected successfully. NexArm can now be controlled according to the controller button descriptions.

1.8 Synchronizer Control ​

NOTE

This section applies only to the NexArm Ultimate Kit equipped with a leader arm.

  1. Press KEY1 to set the NexArm robotic arm to ESP-NOW mode.
  1. Alternatively, use Peripheral & Chassis in the PC software: click Enable ESP-NOW, change the channel to 2, click Set Channel, and click Pair. To control multiple NexArm units with the leader arm, click Scan.
  1. After the mode switch is successful, power on the leader arm. NexArm automatically pairs with the leader arm. The leader arm can control NexArm in real time for synchronized motion.
