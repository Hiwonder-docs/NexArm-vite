① `launch_setup` Function

```py
def launch_setup(context):
    mode = LaunchConfiguration('mode', default=1)
    mode_arg = DeclareLaunchArgument('mode', default_value=mode)

    sdk_package_path = get_package_share_directory('sdk')
    large_models_examples_package_path = get_package_share_directory('large_models_examples')

    sdk_launch = IncludeLaunchDescription(
        PythonLaunchDescriptionSource(
            os.path.join(sdk_package_path, 'launch/armpi_ultra.launch.py')),
    )

    large_models_examples_launch = IncludeLaunchDescription(
        PythonLaunchDescriptionSource(
            os.path.join(large_models_examples_package_path, 'launch/start.launch.py')),
        launch_arguments={'mode': mode}.items(),
    )


    llm_control_servo_node = Node(
        package='large_models_examples',
        executable='llm_control_servo',
        output='screen',
    )

    return [mode_arg,
            sdk_launch,
            large_models_examples_launch,
            llm_control_servo_node,
            ]
```

This function loads **launch/armpi_ultra.launch.py** from the **sdk** package to start low-level control services for the robotic arm, including servo drivers and kinematics calculations, providing hardware support for subsequent control. It loads **launch/start.launch.py** from the **large_models_examples** package to start large-model-related services, passing the `mode` parameter via `launch_arguments` to control the operating mode of the large model, such as different interaction logic or function switches. It declares `llm_control_servo_node` to start the `llm_control_servo` executable in the **large_models_examples** package. Its core function is to convert large model outputs into robotic arm control commands, realizing a closed loop from large model decision to robotic arm action, with logs output to the screen.

This function creates and returns a `LaunchDescription` object, calling the `launch_setup` function via `OpaqueFunction` as the standard entry point for the ROS 2 launch file.

⑪ `process` Method

```py
    def process(self):
        while self.running:
            if self.llm_result:
                msg = String()
                if 'action' in self.llm_result:  # If a corresponding action is returned, extract it and proceed with processing.
                    result = eval(self.llm_result[self.llm_result.find('{'):self.llm_result.find('}') + 1])
                    # self.get_logger().info(str(result))
                    action_list = []
                    if 'action' in result:
                        action_list = result['action']
                    if 'response' in result:
                        response = result['response']
                    msg.data = response
                    self.tts_text_pub.publish(msg)
                    for i in action_list:
                        if self.interrupt:
                            self.get_logger().info('interrupt')
                            break
                        if 'set_position' in i:
                            eval('self.' + i)
                        elif 'move' in i:
                            eval('self.' + i)
                        else:
                            eval(i)
                else:  # No corresponding action, just respond.
                    response = self.llm_result
                    msg.data = response
                    self.tts_text_pub.publish(msg)
                self.action_finish = True 
                self.llm_result = ''
            else:
                time.sleep(0.01)
            if self.play_audio_finish and self.action_finish:
                    self.play_audio_finish = False
                    self.action_finish = False
                    msg = SetBool.Request()
                    msg.data = True
                    self.send_request(self.awake_client, msg)
        rclpy.shutdown()
```

The main processing loop continuously checks `llm_result` from the large model output, parsing the action list `action` and response text `response`. It publishes response text to the TTS node for speech playback and sequentially executes actions, such as `set_position` for servo control, `move` for robotic arm movement, and `time.sleep` for delay. After actions and speech are completed, it re-enables the wake-up function to await the next command.

    def process(self):
        while self.running:
            if self.llm_result:
                msg = String()
                if 'action' in self.llm_result: # If a corresponding action is returned, extract it and proceed with processing.
                    result = eval(self.llm_result[self.llm_result.find('{'):self.llm_result.find('}') + 1])
                    # result = json.loads(self.llm_result)
                    if 'action' in result:
                        text = result['action']
                        # Use regular expressions to extract all strings inside.
                        pattern = r"color_sorting\((['\"][^'\"]+['\"](?:\s*,\s*['\"][^'\"]+['\"])*)\)" 
                        # Use re.search to find the matching result.
                        match = re.search(pattern, text)
                        # Extract the result.
                        if match:
                            # Retrieve all argument parts (the content inside the parentheses).
                            params = match.group(1)
                            # Use regular expressions to split the string arguments.
                            colors = re.findall(r"['\"]([^'\"]+)['\"]", params)
                            self.get_logger().info(str(colors))
                            color_msg = SetStringBool.Request()
                            for i in ['red', 'green', 'blue', 'tag_1', 'tag_2', 'tag_3']:
                                color_msg.data_str = i
                                if i in colors:
                                    color_msg.data_bool = True
                                else:
                                    color_msg.data_bool = False
                                self.send_request(self.set_target_client, color_msg)
                            # Enable sorting.
                            start_msg = SetBool.Request()
                            start_msg.data = True 
                            self.send_request(self.start_client, start_msg)
                    if 'response' in result:
                        msg.data = result['response']
                else: # No corresponding action, just respond.
                    msg.data = self.llm_result
                self.tts_text_pub.publish(msg)
                self.action_finish = True
                self.llm_result = ''
            else:
                time.sleep(0.01)
            if self.play_audio_finish and self.action_finish:
                self.play_audio_finish = False
                self.action_finish = False
                msg = SetBool.Request()
                msg.data = True
                self.send_request(self.awake_client, msg)
        rclpy.shutdown()

## 10.2 Embodied AI Applications

Embodied intelligence is an essential branch in the field of artificial intelligence, emphasizing that agents achieve autonomous learning and decision-making through physical interactions with the environment. Its core philosophy lies in "intelligence originating from dynamic interactions between the body and the environment", breaking through the limitations of traditional AI that relies on static data, and finding wide applications across industry, healthcare, services, education, and defense.

<img class="common_img" src="../_static/media/chapter_12/section_9/media/image1.png" style="width:800px"  />

A key branch of embodied intelligence involves multimodal information fusion. Multimodal information fusion refers to the effective integration of data from different modalities, such as text, images, and voice, to obtain a more comprehensive and accurate information representation. This process is particularly critical in the field of artificial intelligence because real-world information is inherently multimodal, and a single modality often fails to provide sufficient context or detail. Therefore, multimodal information fusion aims to enhance model performance and robustness by combining data across multiple modalities.

Methods for multimodal information fusion can be broadly categorized as follows:

**Early Fusion**: Merges data from different modalities in the early stages of data processing. This method usually occurs at the input layer, mapping raw data to the same space through data alignment and transformation techniques to generate richer and more expressive data representations. For instance, in image and voice fusion, data from both modalities can be directly concatenated as input to the neural network.

<img class="common_img" src="../_static/media/chapter_12/section_9/media/image2.png" style="width:800px"  />

**Late Fusion**: Fuses data from different modalities at intermediate layers or the output layer of the model. This method allows specific algorithms to be trained for each modality, facilitating future additions or exchanges of different modalities. For example, results of image recognition and text analysis can be combined to arrive at the final decision.

<img class="common_img" src="../_static/media/chapter_12/section_9/media/image3.png" style="width:800px"  />

**Hybrid Fusion**: Combines the advantages of early fusion and late fusion, conducting multiple fusions at different processing stages. This method fully utilizes the complementarity among different modalities, improving model performance and robustness.

<img class="common_img" src="../_static/media/chapter_12/section_9/media/image4.png" style="width:800px"  />

**Feature-Level Fusion**: Maps features extracted from multiple modalities into a feature vector through specific transformations, feeding it into a classification model to obtain the final decision. This method fuses different types of data during the feature extraction stage.

<img class="common_img" src="../_static/media/chapter_12/section_9/media/image5.png" style="width:800px"  />

**Decision-Level Fusion**: Combines decisions obtained from different modal information to arrive at the final decision. This method exhibits good anti-interference capability with relatively low requirements for sensor performance and types, although it may entail notable information loss.

<img class="common_img" src="../_static/media/chapter_12/section_9/media/image6.png" style="width:800px"  />

**Deep Fusion**: Occurs during the feature extraction stage, mixing multimodal data in the feature space to obtain fused features, compensating for missing features in other modalities, and then applying these fused features in the prediction stage for classification or regression tasks.

<img class="common_img" src="../_static/media/chapter_12/section_9/media/image7.png" style="width:800px"  />

Multimodal information fusion not only holds significant theoretical importance but also demonstrates enormous potential in practical applications. In fields such as autonomous driving, medical image analysis, and human-robot interaction, multimodal information fusion technology has seen broad adoption, significantly enhancing system performance and reliability.

def launch_setup(context):
    mode = LaunchConfiguration('mode', default=1)
    mode_arg = DeclareLaunchArgument('mode', default_value=mode)

    peripherals_package_path = get_package_share_directory('peripherals')
    sdk_package_path = get_package_share_directory('sdk')
    large_models_examples_package_path = get_package_share_directory('large_models_examples')

    # Launch depth_camera_launch
    depth_camera_launch = IncludeLaunchDescription(
        PythonLaunchDescriptionSource(
            os.path.join(peripherals_package_path, 'launch/depth_camera.launch.py')),
    )

    # Launch sdk_launch and large_models_examples_launch after 5 seconds
    delayed_launch = TimerAction(
        period=5.0,  # Delay time is 5 seconds
        actions=[
            IncludeLaunchDescription(
                PythonLaunchDescriptionSource(
                    os.path.join(sdk_package_path, 'launch/armpi_ultra.launch.py')),
            ),
            IncludeLaunchDescription(
                PythonLaunchDescriptionSource(
                    os.path.join(large_models_examples_package_path, 'launch/start.launch.py')),
                launch_arguments={'mode': mode}.items(),
            ),
        ]
    )

    vllm_with_camera_node = Node(
        package='large_models_examples',
        executable='vllm_with_camera',
        output='screen',
    )

    return [depth_camera_launch,  # Launch depth_camera_launch immediately
            delayed_launch,       # Launch sdk_launch and large_models_examples_launch after delay
            vllm_with_camera_node,
            ]
```

This function immediately loads **launch/depth_camera.launch.py** from the **peripherals** package to start the depth camera node, providing RGB images and depth data as visual input foundations. It delays launching core services through `TimerAction` with a 5-second delay, ensuring that the depth camera finishes initialization and outputs data stably before starting dependent services. It loads **launch/armpi_ultra.launch.py** from the **sdk** package to start low-level control services for the robotic arm, such as servo drivers and kinematics calculations, providing hardware support for subsequent action execution. It loads **launch/start.launch.py** from the **large_models_examples** package to start large model services, passing the `mode` parameter to control its operating mode, such as different inference logic and interaction methods. It declares `vllm_with_camera_node` to start the `vllm_with_camera` executable in the **large_models_examples** package, combining depth camera data with large model capabilities, such as visual question answering and scene understanding, to achieve a closed loop of visual input to large model decision to robotic arm interaction, with logs output to the screen.

⑬ `process` Method

```python
    def process(self):
        action_list = []
        action_finish = False
        while self.running:
            if self.llm_result:
                try:
                    self.get_logger().info(f'llm_result: {self.llm_result}')
                    if 'action' in self.llm_result:  # If there is a corresponding action returned, extract and process it
                        if self.llm_result.startswith("```") and self.llm_result.endswith("```"):
                            self.llm_result = self.llm_result.strip("```").replace("json\n", "").strip()
                        action_list = json.loads(self.llm_result)['action']
                        action_finish = False
                    else:
                        action_finish = True
                except BaseException as e:
                    print(e)
                self.llm_result = ''
            else:
                if action_list:
                    # self.get_logger().info(f'{self.transport_finished}')
                    if self.transport_finished:
                        action = action_list[0]
                        if 'remember' in action:        # Remember position
                            self.remember_position()
                        elif 'recovery' in action:       # Recover
                            self.recovery(action[0])
                        elif 'pick' in action:            # Pick object
                            self.get_object_position(action[0])
                        elif 'place' in action:            # Place object
                            self.get_object_position(action[0], action[-1])
                        elif 'pick_and_place' in action:   # Pick and place on something
                            self.get_object_position(action[0], action[-1])
                        elif 'restore' in action:          # Restore a specific object
                            self.object_restore(action[0])
                        del action_list[0]
                        if not action_list:
                            action_finish = True
                    else:
                        time.sleep(0.1)
                else:
                    time.sleep(0.02)
            if action_finish:
                action_finish = False
                msg = SetBool.Request()
                msg.data = True
                self.send_request(self.awake_client, msg)
        rclpy.shutdown()
```

The main processing loop parses the action list returned by the large model, such as remembering positions, recovery, picking, and placing, sequentially calling corresponding functions like `remember_position` and `recovery`, and re-enables the wakeup function upon completion.

def launch_setup(context):
    mode = LaunchConfiguration('mode', default=1)
    mode_arg = DeclareLaunchArgument('mode', default_value=mode)

    peripherals_package_path = get_package_share_directory('peripherals')
    sdk_package_path = get_package_share_directory('sdk')
    large_models_examples_package_path = get_package_share_directory('large_models_examples')

    # Launch depth_camera_launch immediately
    depth_camera_launch = IncludeLaunchDescription(
        PythonLaunchDescriptionSource(
            os.path.join(peripherals_package_path, 'launch/depth_camera.launch.py')),
    )

    control_launch = IncludeLaunchDescription(
        PythonLaunchDescriptionSource(
            os.path.join(sdk_package_path, 'launch/armpi_ultra.launch.py')),
    )

    # Launch sdk_launch, large_models_examples_launch, intelligent_grasp_node, and vllm_dietitianl_node after 5 seconds
    delayed_launch = TimerAction(
        period=5.0,  # Delay time is 5 seconds
        actions=[            
            IncludeLaunchDescription(
                PythonLaunchDescriptionSource(
                    os.path.join(large_models_examples_package_path, 'launch/start.launch.py')),
                launch_arguments={'mode': mode}.items(),
            ),
            Node(
                package='large_models_examples',
                executable='intelligent_grasp',
                output='screen',
            ),
            Node(
                package='large_models_examples',
                executable='vllm_dietitianl',
                output='screen',
            ),
        ]
    )

    return [mode_arg,
            depth_camera_launch,  # Launch immediately
            control_launch,
            delayed_launch,        # Launch other parts after 5 seconds
            ]
```

This function immediately loads **launch/depth_camera.launch.py** from the **peripherals** package to start the depth camera node, providing RGB images and depth data as visual input for object recognition, positioning, and analysis. It delays launching core services through `TimerAction` with a 5-second delay, ensuring the depth camera finishes initialization. It loads **launch/armpi_ultra.launch.py** from the **sdk** package to start low-level control services for the robotic arm, such as servo drivers and kinematics calculations, providing hardware support for intelligent grasping. It loads **launch/start.launch.py** from the **large_models_examples** package to start large model services, passing the `mode` parameter to control the operating mode. It starts the `intelligent_grasp` executable in the **large_models_examples** package as the core grasping node to implement vision-based precision grasping logic. It starts the `vllm_dietitianl` executable in the **large_models_examples** package to combine visual data with large model reasoning for object analysis and interaction, with logs output to the screen.

⑨ `process` Method

```python
    def process(self):
        while self.running:
            if self.vllm_result:
                try:
                    if self.vllm_result.startswith("```") and self.vllm_result.endswith("```"):
                        self.vllm_result = self.vllm_result.strip("```").replace("json\n", "").strip()
                    self.vllm_result = json.loads(self.vllm_result)
                    box = self.vllm_result['xyxy']
                    box = self.client.data_process(box, 640, 400)
                    label = self.vllm_result['object']
                    response = self.vllm_result['response']
                    self.get_logger().info(f'label: {label} box: {box}')

                    msg = SetBox.Request()
                    msg.label = label
                    msg.box = box
                    self.send_request(self.set_target_client, msg)
                    # Enable sorting
                    msg = SetBool.Request()
                    msg.data = True
                    self.send_request(self.start_client, msg)
                    time.sleep(2)
                    msg = String()
                    msg.data = response
                    self.tts_text_pub.publish(msg)
                except BaseException as e:
                    msg = String()
                    msg.data = self.vllm_result
                    self.tts_text_pub.publish(msg)
                    self.get_logger().info(f'error: {e}')
                self.action_finish = True
                self.vllm_result = ''
            else:
                time.sleep(0.01)
            if self.play_audio_finish and self.action_finish:
                self.play_audio_finish = False
                self.action_finish = False
                msg = SetBool.Request()
                msg.data = True
                self.send_request(self.awake_client, msg)
        rclpy.shutdown()
```

The main processing loop parses large model results, extracts object names and coordinates, sets grasping targets, and launches intelligent grasping. It publishes TTS replies, and re-enables the wakeup function upon completion to await the next command.
