# 14. NexArm + Advanced Sorting Sandbox

The **NexArm Advanced Sorting Sandbox Kit** is a comprehensive robotic arm experiment kit designed for robotic vision sorting, waste classification, and advanced ROS applications. It is equipped with core modules including the NexArm robotic arm, a 3D depth camera, a metal baseplate for the advanced sorting sandbox scene, a visual recognition panel measuring 264 × 264 mm, colored plastic trays, a 7-inch touch screen, color cubes, waste/tag cards, and an optional WonderEcho Pro AI voice interaction box. The kit supports not only color block recognition, object grasping, and categorized sorting, but also waste recognition and sorting combined with the YOLO model. It is suitable for studying robotic arm vision positioning, intelligent sorting, object detection, and full-workflow ROS development.

### 14.2.3 Robot Startup Instructions

This section covers the power-on status of the robot and functional verification of each module. After completion, proceed to subsequent chapters to learn app control.

To connect to the robot via remote tools, explore additional robot applications, and inspect programs, refer to [1. Tutorials / 1. NexArm User Manual / 1.5 Development Environment Setup and Configuration](https://wiki.hiwonder.com/projects/NexArm/en/ros-version/docs/1.%20NexArm%20User%20Manual.html#_1-5-development-environment-setup-and-configuration).

> [!NOTE]
>
> **The robotic arm must be secured firmly before starting. Sandbox kits must ensure the base screws are tightened. The robotic arm generates swing and inertia during startup and operation. If unsecured, it may tip over, fall, or sustain damage, and may also pose safety risks.**

1. Connect the 12 V 5 A power adapter to the ESP32 controller. Following this order ensures proper operation of all robotic arm hardware.

   <img class="common_img" src="../_static/media/chapter_1/section_3/media/image2.png" style="width:500px"  />

2. Do not stack robotic arms to prevent locked-rotor states upon power-on, which can damage the servos.

3. Do not operate the robotic arm under heavy loads for extended periods, as this will also shorten servo service life or cause permanent damage.

4. Maintain a safe distance from the robot before starting to prevent injury caused by accidental contact after power-on.

5. Push the power switch to the **ON** position.

<img class="common_img" src="../_static/media/chapter_1/section_3/media/image3.png" style="width:500px"  />

Wait approximately 1 minute. The robotic arm returns to its initial posture, and the buzzer emits a short beep, indicating that device startup is complete.

> [!NOTE]
>
> **If the buzzer does not emit a short beep, a hardware issue such as a buzzer malfunction may exist. This does not typically occur under normal usage. If this happens, contact customer support for assistance.**

* **Adjusting Color Thresholds**

1. Open the LAB Tool. In the color list of the recognition adjustment area, select the color requiring threshold adjustment, using red as an example here.

<img class="common_img" src="../_static/media/chapter_1/section_5/media/image21.png" style="width:300px"  />

2. Set the **min** values of the L, A, and B components to **0**, and set the **max** values to **255**.

<img class="common_img" src="../_static/media/chapter_1/section_5/media/image22.png" style="width:800px"  />

3. Place the colored object within the camera field of view. Refer to the LAB color space distribution diagram, and adjust the L, A, and B components toward the target color range.

<img class="common_img" src="../_static/media/chapter_1/section_5/media/image23.png" style="width:600px"  />

Red is located near **+a**, so increase the A component by keeping its **max** value unchanged and increasing its **min** value until the colored object area in the left image display turns white while other areas turn black.

<img class="common_img" src="../_static/media/chapter_1/section_5/media/image24.png" style="width:800px"  />

4. Adjust the remaining L and B components according to the operating environment. If the red color appears lighter, increase the **min** value of the L component. If it appears darker, decrease the **max** value of the L component. If the red color has a warmer tone, increase the **min** value of the B component. If it has a cooler tone, decrease the **max** value of the B component.

<img class="common_img" src="../_static/media/chapter_1/section_5/media/image25.png" style="width:700px"  />

The table below provides parameter reference information for LAB threshold adjustment:

| Color Component | Value Range | Corresponding Color Interval |
| :---: | :---: | :---: |
| L | 0-255 | Black-White (-L to +L) |
| A | 0-255 | Green-Red (-a to +a) |
| B | 0-255 | Blue-Yellow (-b to +b) |

5. Click **Save** in the recognition adjustment area to save the color threshold adjustment parameters.

<img class="common_img" src="../_static/media/chapter_1/section_5/media/image26.png" style="width:800px"  />

### 14.5.3 Pixel Positioning

1. Select **Pixel Positioning** in **Mode**, and place the color block at the center position.

   <img class="common_img" src="../_static/media/chapter_16/section_3/media/image3.png" style="width:800px"  />

2. Click the color block in the color calibration area with the mouse. The robotic arm automatically samples the color, recognizes the target, and executes only the grasping motion. Adjust the positioning offsets for X, Y, and Z based on the grasping results. Note that **Save** must be clicked after modifying values for changes to take effect.

   <img class="common_img" src="../_static/media/chapter_16/section_3/media/image4.png" style="width:800px"  />

   As shown in the figure above, adjusting the X-axis value moves the robotic arm forward or backward. For example, setting X to a positive value moves the robotic arm forward.
   Adjusting the Y-axis value moves the robotic arm left or right. For example, setting Y to a positive value moves the robotic arm to the left.
   Adjusting the Z-axis value moves the robotic arm up or down. For example, setting Z to a positive value moves the robotic arm upward.

   <img class="common_img" src="../_static/media/chapter_16/section_3/media/image5.png" style="width:800px"  />

3. After adjusting the parameters, click **Save** first to save and apply the configured data to the robotic arm grasping program. Next, click **Home** to return to the robotic arm recognition and grasping state. Finally, click the color block again with the mouse. The robotic arm automatically samples the color, identifies the position, and performs grasping.

   <img class="common_img" src="../_static/media/chapter_16/section_3/media/image6.png" style="width:800px"  />

4. Once the color block can be successfully grasped at the center position, place the wooden block within the bounding box on the map. Click the color block with the mouse, and adjust the positioning Y **Scale** according to the grasping performance of the mechanical gripper. This parameter adjusts the gripper opening size along the Y-axis. Once the center block offset is properly calibrated, only the scale needs adjustment. Ensure that all four corners of the bounding box can be grasped normally.

   <img class="common_img" src="../_static/media/chapter_16/section_3/media/image7.png" style="width:800px"  />

### 14.5.4 Depth Positioning

* **Scene 3 Placement Parameter Description**

These represent `place_targets` in the robotic arm program, which correspond to spatial coordinate points for different targets. The three numbers following each target generally represent:

```text
[x, y, z]
```

The unit is **meters**, representing the position coordinates to which the robotic arm end-effector moves.

| Name | Description |
| :--- | :--- |
| `yellow` | Placement position for yellow color block. |
| `red` | Placement position for red color block. |
| `green` | Placement position for green color block. |
| `blue` | Placement position for blue color block. |
| `residual_waste` | Placement position for other waste / residual waste. |
| `food_waste` | Placement position for food waste. |
| `hazardous_waste` | Placement position for hazardous waste. |
| `recyclable_waste` | Placement position for recyclable waste. |
| `center` | Scene center point, typically used for positioning, calibration, or as a reference point. |
| `left_top` | Upper-left reference point of the scene. |
| `right_top` | Upper-right reference point of the scene. |
| `left_bottom` | Lower-left reference point of the scene. |
| `right_bottom` | Lower-right reference point of the scene. |
| `tag1` | Position corresponding to tag 1. |
| `tag2` | Position corresponding to tag 2. |
| `tag3` | Position corresponding to tag 3. |
| `tag_stackup` | Stacking position for tags, typically used for centralized placement after tag sorting. |

For example:

```yaml
yellow:
- -0.04
- 0.23
- 0.08
```

This indicates that the yellow color block is placed at coordinate `x = -0.04, y = 0.23, z = 0.08`. The actual orientation, such as whether the positive `y` direction represents left or right, is subject to the coordinate system defined in the robotic arm program.

(5) Receiving YOLO Results

```python
def get_object_callback(self, msg):
    objects = msg.objects
    if not self.enable_transport:
        return
    candidates = []
    for i in objects:
        raw_angle = float(i.angle)
        if i.angle < 0:
            i.angle = 90 - abs(i.angle)
        target = [
            i.class_name,
            0,
            (int(i.box[0]), int(i.box[1])),
            (int(i.box[2]), int(i.box[3])),
            i.angle,
            raw_angle
        ]
        if i.class_name in self.target_list:
            category = self._waste_category_for_class(i.class_name)
            if category is not None:
                candidates.append((category, target, float(getattr(i, 'score', 0.0)), list(i.box)))
```

This callback subscribes to `yolo/object_detect`, filters out targets currently permitted for sorting, and converts specific waste labels into general waste categories. The program also preserves bounding box orientation angles for subsequent grasping pose calculations.

(8) Scene 3 Direct Placement Function

```python
SCENE3_PLACE_POSES = {
    'food_waste':       (0.305, -0.19,  0.18,  -43.0),
    'recyclable_waste': (0.195, -0.205, 0.18,  -43.0),
    'hazardous_waste':  (0.085, -0.21,  0.185, -45.0),
    'residual_waste':   (-0.05, -0.21,  0.18,  -45.0),
    'yellow':           (-0.08,  0.29,  0.065, -65.0),
    'red':              (0.09,   0.29,  0.06,  -65.0),
    'green':            (0.29,   0.30,  0.07,  -65.0),
    'blue':             (0.185,  0.30,  0.06,  -65.0),
}

def _scene3_direct_place(self, target_key):
    pose = self.SCENE3_PLACE_POSES.get(target_key)
    x_mm, y_mm, z_mm, pitch_deg = pose[0]*1000, pose[1]*1000, pose[2]*1000, pose[3]
    self.publish_arm(x_mm, y_mm, z_mm, pitch_deg, 0.0, -45.0, 1500)
    time.sleep(2.0)
    self.publish_arm(x_mm, y_mm, z_mm, pitch_deg, 0.0, pick_and_place.CLAW_OPEN, 400)
    time.sleep(0.5)
    self.publish_arm(x_mm, y_mm, z_mm + 50.0, pitch_deg, 0.0, pick_and_place.CLAW_OPEN, 800)
```

The first three values in `SCENE3_PLACE_POSES` represent placement coordinates in meters, and the fourth represents the placement pitch angle in degrees. During execution, the function converts meters to millimeters and publishes them to `/ros_robot_controller/arm/set_coords`, completing the movements of reaching, opening the gripper, and lifting.
