# 1. Getting Started

## 1.1 Product Overview

<img class="common_img" src="../_static/media/chapter_1/section_2/media/image22.png" style="width:600px">

NexArm is an open-source six-axis robotic arm designed for embodied intelligence, robotics development, and artificial intelligence applications. Integrating mechanical control, teach programming, leader-follower control, and imitation learning into a single platform, it provides a comprehensive robotics development platform for developers, academic research institutions, and robotics enthusiasts. Compatible with mainstream open-source frameworks such as LeRobot and Hugging Face, it enables quick setup for algorithm validation, data collection, model training, and intelligent control.

NexArm supports fundamental motion control, trajectory teaching, action recording and playback, leader-follower cooperative control, imitation learning data collection, and AI model training and deployment. It can be widely applied in robotics teaching experiments, embodied intelligence research, reinforcement learning and imitation learning development, vision-based grasping, intelligent interaction verification, and personal development projects, helping quickly bridge the gap from robotic arm control to end-to-end AI application deployment.
